Pipeline Architecture

  1. Frame Capture & Preprocessing

    Resizes incoming 854×480 frame to 800×450 for optimal cache locality.

  2. Background Subtraction (MOG2)

    Generates motion mask with Gaussian Mixture Models, isolating dynamic ocean life from stationary seabed.

  3. Morphological Filtering & Contours

    Applies 5×5 kernel opening & closing, extracting contours with minimum bounding area > 1,000 px.

  4. KNN Inference & HUD Rendering

    Crops region of interest, normalizes to 64×64 RGB, and runs k-nearest neighbors classification.

Developer Reference

Terminal & Script Execution Guide

How to run individual ReefLens scripts locally directly in your terminal:

1. Activate Virtual Environment 
source .venv/bin/activate

Loads the newly created macOS Python 3.11 environment with all dependencies.

2. Run Single Image Prediction (predict.py) 
./.venv/bin/python predict.py

Prompts for an image path, executes KNN classification, and opens an OpenCV display window.

3. Run Real-time Video Detection (video.py) 
./.venv/bin/python video.py

Launches MOG2 background motion detection with bounding boxes on marine_video.mp4. Press 'Q' to exit.

4. Run SIFT Feature Matcher (main1.py) 
./.venv/bin/python main1.py

Runs SIFT keypoint detection and FLANN matching against the dataset templates. Press 'Q' to quit.

5. Evaluate Model Accuracy (evaluate.py) 
./.venv/bin/python evaluate.py

Computes precision, recall, and 88.84% accuracy across all 11 classes on the test split.

6. Retrain KNN Model (train.py) 
./.venv/bin/python train.py

Walks through dataset/, fits KNeighborsClassifier(k=5), and saves fresh model artifacts.
